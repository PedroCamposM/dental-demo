- [ ] Tocar 16, 26 y 36: el título dice «Agregar hallazgo en las piezas 16, 26, 36» y el
      campo «Piezas» muestra «16, 26, 36». También se puede escribir la lista a mano.
- [ ] Caries, superficie oclusal, sigla CE → «Agregar en 3 piezas»: aparecen tres hallazgos,
